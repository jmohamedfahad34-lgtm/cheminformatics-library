
# MoleculeVerse - Cheminformatics Library

An interactive cheminformatics web application built using
Python, Streamlit, RDKit and Pandas.

## Features
- Search and explore chemical molecules
- View molecular formulas and 2D structures
- Calculate molecular descriptors
- Compare multiple molecules
- Filter by molecular weight and category
- Export molecule data to CSV

## Technologies
- Python
- Streamlit
- RDKit
- Pandas

## Run locally

Install the dependencies:

    pip install -r requirements.txt

Start the app:

    streamlit run app.py
